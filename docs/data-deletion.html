Data Deletion Instructions

Threads Agent · Last updated: 19 August 2026

You can have every piece of data Threads Agent holds about you deleted. There is no form to fill in — one email is enough.

How to request deletion

  1. Send an email to hoarder_runtime_0z@icloud.com with the subject “Data deletion request”.
  2. Include the Threads username (@handle) of the account you connected, so we can identify the records.
  3. Send it from any address — we confirm ownership by replying through the connected account if needed.

We confirm receipt within 3 business days and complete deletion within 30 days.

What gets deleted

  • Your Threads user ID, username and profile picture.
  • Your OAuth access token (revoked immediately).
  • All posts, drafts, schedules and metrics stored by the App.
  • Technical logs tied to your account.

After deletion the data cannot be restored. Content already published on Threads itself stays on Threads — delete it there if you want it gone.

Revoking access yourself

You can cut off the App’s access at any moment, independently of a deletion request: in Threads open Settings → Website permissions and remove Threads Agent. This revokes the token but does not by itself erase data already stored — email us for that.

Видалення даних

Threads Agent · Оновлено: 19 серпня 2026

Ви можете видалити всі дані, які Threads Agent зберігає про вас. Форми немає — достатньо одного листа.

Як подати запит

  1. Надішліть лист на hoarder_runtime_0z@icloud.com з темою «Data deletion request».
  2. Вкажіть ім’я користувача Threads (@handle) підключеного акаунта.
  3. Підтвердження отримання — протягом 3 робочих днів, видалення — протягом 30 днів.

Що видаляється

  • Threads user ID, ім’я користувача, фото профілю.
  • OAuth-токен (відкликається одразу).
  • Усі пости, чернетки, розклади й метрики, збережені застосунком.
  • Технічні логи, пов’язані з акаунтом.

Після видалення дані не відновлюються. Контент, уже опублікований у Threads, лишається в Threads — видаляйте його там.

Відкликати доступ самостійно

У Threads: Налаштування → Дозволи вебсайтів → прибрати Threads Agent. Це відкликає токен, але не стирає збережені дані — для цього напишіть листа.
